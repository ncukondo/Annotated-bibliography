# Cognitive Load Theory

This is a theory proposed by Sweller that deals with working memory in learning. Human memory consists of sensory memory, working memory, and long-term memory, and working memory becomes a bottleneck during learning. Sweller classified the load on working memory into three types: intrinsic cognitive load related to task performance, extraneous cognitive load unrelated to learning, and germane cognitive load related to memory and knowledge construction. He suggested that learning can be promoted by reducing extraneous cognitive load, adjusting intrinsic cognitive load, and optimizing germane cognitive load.

- Working Memory
  - Intrinsic Cognitive Load
  - Extraneous Cognitive Load
  - Germane Cognitive Load

[@Sweller1988-bj; @Van_Merrienboer2010-eq]

## How to Utilize

- Reduce Extraneous Cognitive Load
  - Improve the way tasks are presented
  - Optimize the surrounding environment
- Optimize Intrinsic and Germane Cognitive Load
  - These loads should not be too high or too low for effective learning
  - Adjust the complexity of tasks
  - Tailor tasks to the learner's experience

[@Van_Merrienboer2010-eq]

## Intrinsic Cognitive Load

Intrinsic cognitive load is the load caused by the cognitive processing required for learners to perform a task. It arises from the complexity of the task, which is determined by the number of elements, the strength of the connections between elements, the number of connections, and the types of connections.

[@Sweller1988-bj; @Van_Merrienboer2010-eq]

### Example

For example, if you are just memorizing a disease name, the intrinsic cognitive load is low because the number of elements is small. However, if you are learning to diagnose a disease, the intrinsic cognitive load is high because you need to combine related symptoms and test results to infer the disease name.

## Extraneous Cognitive Load

Extraneous cognitive load is the load caused by cognitive processing that is not necessary for performing the task. It arises from the way tasks are presented and the surrounding environment.

[@Sweller1988-bj; @Van_Merrienboer2010-eq]

### Example

For example, if the materials for a case study are difficult to read, the extraneous cognitive load is high. If it is not clear what task to perform with the presented case, the extraneous cognitive load is also high. Additionally, if there is a lot of noise around, the extraneous cognitive load increases.

## Germane Cognitive Load

Germane cognitive load is the load caused by cognitive processing necessary for learning. It varies depending on the relationship between the learner's existing knowledge or schemas and the content to be learned.

[@Sweller1988-bj; @Van_Merrienboer2010-eq]

### Example

For example, if you already have knowledge of diagnosing related diseases, the germane cognitive load is low when learning to diagnose a new disease. Similarly, if you encounter similar cases consecutively in a clinic, the germane cognitive load is low.
